# เอกสารขอบเขตงาน (Scope of Work)
## โครงการระบบจัดการ PDF Report จาก Innovian เพื่อรองรับการจัดเก็บเอกสารใน ePHIS

**ลูกค้า:** Meditop Co., Ltd.  
**ผู้พัฒนา:** คุณปัญญา พ่วงจินดา  
**วันที่เอกสาร:** 30/06/2026  

เอกสารฉบับนี้จัดทำขึ้นเพื่อใช้แนบประกอบใบเสนอราคา สำหรับสรุปขอบเขตงานและสิ่งที่จะส่งมอบในโครงการพัฒนาระบบจัดการ `PDF report` จาก `Innovian` เพื่อรองรับกระบวนการจัดเก็บเอกสารใน `ePHIS`

เอกสารนี้ใช้เพื่อให้ทุกฝ่ายเข้าใจตรงกันในภาพรวมของงาน ก่อนการดำเนินโครงการอย่างเป็นทางการ

---

## 1. วัตถุประสงค์ของโครงการ

โครงการนี้มีวัตถุประสงค์เพื่อพัฒนาระบบหรือ utility สำหรับช่วยจัดการ `PDF report` จาก `Innovian` ให้สามารถนำไปใช้งานต่อใน workflow ของโรงพยาบาลได้อย่างเป็นระบบมากขึ้น โดยมุ่งเน้น

- ลดภาระงานจากการตรวจสอบและจัดการไฟล์ด้วยมือ
- ลดความเสี่ยงจากการตั้งชื่อไฟล์ที่ไม่เหมาะสมหรือไฟล์ถูกเขียนทับ
- รองรับกรณีผู้ป่วยมีหลาย case ในวันเดียวกัน
- รองรับการประมวลผลและจัดส่งเอกสารแบบอัตโนมัติ
- มี `log` สำหรับตรวจสอบผลการทำงานย้อนหลัง

---

## 2. ขอบเขตงาน

ขอบเขตงานหลักของโครงการประกอบด้วย

### 2.1 วิเคราะห์ workflow และข้อมูลที่เกี่ยวข้อง

- วิเคราะห์ workflow การจัดการเอกสารร่วมกับเจ้าหน้าที่ที่เกี่ยวข้อง
- วิเคราะห์ตัวอย่างไฟล์ PDF และข้อมูลที่ใช้สำหรับการประมวลผล

### 2.2 ออกแบบแนวทางการประมวลผลและการตั้งชื่อไฟล์

- ออกแบบ logic สำหรับตรวจสอบและแยกแต่ละ case
- ออกแบบรูปแบบการตั้งชื่อไฟล์ที่เหมาะสมยิ่งขึ้นสำหรับการจัดเก็บใน ePHIS

### 2.3 พัฒนาระบบตรวจสอบความครบถ้วนของเอกสาร

- ตรวจสอบความสัมพันธ์ระหว่างรายการ case กับไฟล์ PDF ที่มีอยู่
- ช่วยระบุกรณีไฟล์ขาด ซ้ำ หรือมีความเสี่ยงต่อการจัดเก็บผิด

### 2.4 พัฒนาระบบรองรับกรณีหลาย case ในวันเดียวกัน

- รองรับกรณีผู้ป่วยรายเดียวมีหลาย encounter หรือหลาย case ในวันเดียวกัน
- ลดความเสี่ยงจากการใช้ชื่อไฟล์ที่ทำให้ไฟล์ถูกแทนที่กัน

### 2.5 พัฒนาระบบประมวลผลและจัดส่งเอกสารอัตโนมัติ

- รองรับการประมวลผลไฟล์ตาม workflow ที่ตกลง
- รองรับการจัดส่งหรือเตรียมไฟล์ปลายทางแบบอัตโนมัติ

### 2.6 บันทึกข้อมูลการประมวลผล

- จัดเก็บ `log` สำหรับใช้ตรวจสอบผลการทำงานและติดตามปัญหาย้อนหลัง

### 2.7 ติดตั้ง ทดสอบ และส่งมอบระบบ

- ติดตั้งระบบตามขอบเขตที่ตกลง
- ทดสอบการทำงานร่วมกับไฟล์ตัวอย่าง
- ส่งมอบพร้อมเอกสารใช้งานเบื้องต้น

---

## 3. สิ่งที่จะส่งมอบ

เมื่อดำเนินโครงการแล้วเสร็จตามขอบเขตที่ตกลง ลูกค้าจะได้รับ

- โปรแกรมหรือ utility สำหรับจัดการ PDF ตาม workflow ที่กำหนด
- logic สำหรับการตรวจสอบ case และการตั้งชื่อไฟล์
- ระบบรองรับกรณีหลาย case ในวันเดียวกัน
- ระบบประมวลผลและจัดส่งเอกสารอัตโนมัติ
- `log` สำหรับตรวจสอบผลการทำงาน
- เอกสารการใช้งานเบื้องต้นและการส่งมอบระบบ

---

## 4. ข้อสมมติฐานสำคัญ

การดำเนินงานตามขอบเขตนี้ตั้งอยู่บนข้อสมมติฐานว่า

- ลูกค้าสามารถจัดเตรียมตัวอย่างไฟล์ PDF จริงสำหรับใช้วิเคราะห์และทดสอบได้
- มีการกำหนด source และ destination workflow ได้ชัดเจน
- ระบบจะทำงานใน environment ที่ตกลงร่วมกัน

---

## 5. สิ่งที่อยู่นอกขอบเขต

รายการต่อไปนี้ไม่รวมอยู่ในขอบเขตฉบับนี้ เว้นแต่จะมีการตกลงเพิ่มเติมเป็นลายลักษณ์อักษร

- การเชื่อมต่อ `API` โดยตรงกับ `ePHIS`
- การเชื่อมต่อฐานข้อมูลโดยตรงกับ `Innovian`
- งาน `OCR` สำหรับ PDF ที่เป็นภาพล้วน
- งาน infrastructure อื่นที่ไม่เกี่ยวข้องกับ workflow นี้
- การเปลี่ยนแปลง requirement หรือการเพิ่ม scope หลังเริ่มโครงการ

---

## 6. เงื่อนไขเพิ่มเติม

- ราคาค่าบริการครอบคลุมการวิเคราะห์ ออกแบบ พัฒนา ติดตั้ง และทดสอบระบบตามขอบเขตที่ตกลงร่วมกัน
- หากมีการเปลี่ยนแปลงความต้องการหรือเพิ่มขอบเขตงานหลังเริ่มโครงการ อาจมีค่าใช้จ่ายเพิ่มเติมตามที่ตกลงร่วมกันภายหลัง

---

## 7. สรุป

โครงการนี้มีเป้าหมายเพื่อพัฒนาระบบจัดการ `Innovian PDF` ให้มีความถูกต้อง เป็นระบบ และรองรับการทำงานอัตโนมัติมากขึ้น เพื่อลดภาระงานของผู้ใช้งานและเพิ่มความพร้อมสำหรับการนำเอกสารเข้าสู่ workflow ของ `ePHIS`

รายละเอียดเพิ่มเติมอาจมีการปรับตามข้อมูลตัวอย่างจริงและข้อสรุปร่วมกันก่อนเริ่มดำเนินงาน
