# FLORA Troubleshooting Guide (A4)

## เมื่อข้อมูลจาก Patient Monitor หรือ Anesthesia Machine ไม่ขึ้นใน FLORA

เอกสารนี้ใช้สำหรับหน้างานในห้องผ่าตัด เมื่อตัวเลขจาก `patient monitor` หรือ `anesthesia machine` ไม่แสดงใน FLORA หรือหยุดอัปเดต

## 1. สังเกตอาการก่อน

ให้ดูว่าเป็นอาการแบบใด

- `Patient Monitor` ไม่ขึ้นข้อมูล เช่น `HR`, `SpO2`, `NIBP`
- `Anesthesia Machine` ไม่ขึ้นข้อมูล เช่น `EtCO2`, `agent`, `FiO2`, ventilator values
- ทั้ง 2 เครื่องไม่ขึ้นข้อมูล
- ข้อมูลเคยขึ้น แต่หยุดอัปเดตไปเอง

## 2. ตรวจสอบแบบเร็วที่หน้าจอ

### กรณีข้อมูลจาก Monitor หาย

เช็กว่าใน FLORA ยังมีค่าจากเครื่องดมยาสลบขึ้นอยู่หรือไม่

- ถ้ามีเฉพาะ `anesthesia machine` แต่ไม่มี `monitor`
  - ให้สงสัยที่สายหรือ USB ของ `monitor`
- ถ้าไม่มีทั้ง 2 ฝั่ง
  - ให้สงสัยที่ `Hidro`, USB hub, หรือ computer connection

### กรณีข้อมูลจาก Anesthesia Machine หาย

เช็กว่าใน FLORA ยังมีค่าจาก monitor ขึ้นอยู่หรือไม่

- ถ้ามีเฉพาะ `monitor` แต่ไม่มี `anesthesia machine`
  - ให้สงสัยที่สายหรือ USB ของ `anesthesia machine`
- ถ้าไม่มีทั้ง 2 ฝั่ง
  - ให้สงสัยที่ `Hidro`, USB hub, หรือ computer connection

## 3. ขั้นตอนแก้ไขเบื้องต้น

ทำตามลำดับนี้ก่อน ไม่ต้องถอดสายทุกจุดพร้อมกัน

### Step 1: เช็กสายอุปกรณ์

- ดูว่าสายจากเครื่องแพทย์ยังเสียบอยู่แน่น
- ดูว่าสาย USB / serial adapter ยังไม่หลวม
- ถ้ามีการขยับเครื่องหรือขยับรถคอมก่อนเกิดปัญหา ให้เช็กสายเป็นพิเศษ

### Step 2: ใช้ USB Hub Switch

ระบบติดตั้ง `USB hub` แบบมีปุ่ม `on/off` แยกแต่ละ port เพื่อให้ reset เฉพาะอุปกรณ์ที่มีปัญหาได้

หลักการใช้งาน

- ปิดสวิตช์ของ port ที่ต่อกับอุปกรณ์ที่มีปัญหา
- รอประมาณ `5 วินาที`
- เปิดสวิตช์กลับ
- รอระบบ reconnect ประมาณ `30-60 วินาที`

ข้อสำคัญ

- ให้ปิดเฉพาะ port ของอุปกรณ์ที่มีปัญหา
- ไม่ต้องปิดทุกช่องพร้อมกัน
- ควรติด label ให้ชัดว่า port ไหนคือ `Monitor` และ port ไหนคือ `Machine`

ตัวอย่าง

- ถ้า `monitor data` หาย ให้ปิด/เปิดเฉพาะ port ของ `Patient Monitor`
- ถ้า `anesthesia machine data` หาย ให้ปิด/เปิดเฉพาะ port ของ `Anesthesia Machine`

### Step 3: ดูว่าข้อมูลกลับมาหรือไม่

หลังเปิด switch กลับ

- รอ `30-60 วินาที`
- ดูว่าค่าบน chart หรือ data status กลับมาหรือยัง
- ถ้าค่ากลับมาแล้ว สามารถใช้งานต่อได้

### Step 4: Restart Hidro / FLORA

ถ้า toggle USB hub แล้วข้อมูลยังไม่กลับมา

- ปิดและเปิด `Hidro`
- ถ้ายังไม่กลับ ให้ปิดและเปิด `FLORA`

ถ้าหน้างานมีผู้รับผิดชอบ IT / support ประจำ ให้แจ้งก่อนทำ restart หากเป็นนโยบายของหน่วยงาน

### Step 5: Restart Computer

ถ้ายังไม่กลับหลังจากทำข้างต้น

- restart computer
- หลังเปิดเครื่องใหม่ รอ `Hidro` และ `FLORA` ทำงานครบก่อน
- ตรวจสอบว่าข้อมูลจากอุปกรณ์กลับมาแล้วหรือไม่

## 4. ถ้ายังไม่หาย ให้แจ้ง support พร้อมข้อมูลนี้

เวลารายงานปัญหา กรุณาระบุให้ครบที่สุด

- ห้องผ่าตัด / room
- วันที่และเวลาเกิดปัญหา
- เป็น `Patient Monitor` หรือ `Anesthesia Machine`
- อาการเป็นแบบใด
  - ไม่ขึ้นตั้งแต่เริ่ม
  - เคยขึ้นแล้วหยุด
  - ขึ้น offline แต่ยังมีข้อมูล
  - ทั้ง 2 เครื่องหายพร้อมกัน
- ได้ลองทำอะไรแล้วบ้าง
  - เช็กสาย
  - toggle USB hub switch
  - restart Hidro
  - restart FLORA
  - restart computer

## 5. สิ่งที่ไม่ควรทำ

- ไม่ควรถอดสายทุกจุดพร้อมกันโดยไม่จำเป็น
- ไม่ควรสลับ USB หลายช่องพร้อมกัน
- ไม่ควรปิด switch ทุกช่องพร้อมกัน ถ้ายังไม่รู้ว่าช่องไหนเป็นของอุปกรณ์ใด

## 6. Quick Decision

### Monitor หายอย่างเดียว

1. เช็กสาย `monitor`
2. toggle USB hub switch ของ `monitor`
3. รอ `30-60 วินาที`
4. ถ้ายังไม่กลับ ให้ restart `Hidro` / `FLORA`

### Anesthesia Machine หายอย่างเดียว

1. เช็กสาย `anesthesia machine`
2. toggle USB hub switch ของ `machine`
3. รอ `30-60 วินาที`
4. ถ้ายังไม่กลับ ให้ restart `Hidro` / `FLORA`

### ทั้ง 2 เครื่องหายพร้อมกัน

1. เช็ก `Hidro` และการเชื่อมต่อที่ computer
2. เช็ก USB hub
3. ถ้าจำเป็นให้ restart `Hidro` / `FLORA`
4. ถ้ายังไม่กลับ ให้ restart computer และแจ้ง support

## 7. หมายเหตุ

FLORA และ Hidro ถูกออกแบบให้ช่วยบันทึกข้อมูลอัตโนมัติ แต่หากเกิดปัญหาการเชื่อมต่อ ข้อมูลสำคัญทางคลินิกยังต้องอาศัยการสังเกตจากอุปกรณ์หลักและการดูแลผู้ป่วยเป็นสำคัญ
